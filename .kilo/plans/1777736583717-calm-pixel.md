# خطة تنفيذ: استبيان المهارات متعدد الأجزاء مع التصميم الجديد

## ملخص
تحويل صفحة استبيان المهارات الحالية من صفحة واحدة بأشرطة تمرير (sliders) إلى استبيان من 3 أجزاء بتصميم جديد (أزرار دائرية 1-5) يدعم تقييم مزدوج: **مستوى المهارة** + **الاهتمام**.

---

### 1.1 إنشاء Migration لإضافة `interest_level`
- **ملف جديد**: `backend/database/migrations/2026_05_02_000001_add_interest_level_to_user_skills.php`
- إضافة عمود `interest_level` (integer, default 1) إلى جدول `user_skills`

### 1.2 تحديث SkillSeeder بالمهارات الجديدة
- **ملف**: `backend/database/seeders/SkillSeeder.php`
- إضافة الفئات الجديدة:
  - **Cybersecurity**: Web Security, Cryptography, Penetration Testing
  - **IoT**: Raspberry Pi, Embedded Systems, Arduino

## المرحلة 3: تعديل الـ Flutter (Frontend)

### 3.1 تحديث UserSkillModel
- **ملف**: `projectforge_app/lib/models/user_model.dart`
- إضافة حقل `interestLevel` إلى `UserSkillModel`
- تحديث `fromJson` لقراءة `pivot.interest_level`

### 3.2 تحديث SkillController
- **ملف**: `projectforge_app/lib/controllers/skill_controller.dart`
- إضافة `RxMap<int, int> selectedInterest = <int, int>{}.obs`
- إضافة دوال: `setInterest()`, `removeInterest()`
- تحديث `saveSkills()` لإرسال `interest_level` بجانب `proficiency_level`
- تحديث `fetchSkills()` لاستعادة القيم المحفوظة مسبقاً (proficiency + interest)
- إضافة منطق التنقل بين الأجزاء الثلاثة:
  - `RxInt currentStep = 0.obs`
  - دوال `nextStep()`, `previousStep()`
  - تقسيم الفئات إلى 3 مجموعات:
    - **الجزء 1**: Frontend, Programming Languages, Backend → عنوان: "استبيان المهارات - الجزء الأول" / "التطوير والبرمجة"
    - **الجزء 2**: Databases, AI/ML, Tools, Cloud, Design → عنوان: "استبيان المهارات - الجزء الثاني" / "البيانات والذكاء الاصطناعي والأدوات"
    - **الجزء 3**: Cybersecurity, IoT, Soft Skills → عنوان: "استبيان المهارات - الجزء الثالث" / "الأمن السيبراني، إنترنت الأشياء، والمهارات الناعمة"

### 3.3 إنشاء Widget جديد: SkillRatingButtons
- **ملف جديد**: `projectforge_app/lib/widgets/skill_rating_buttons.dart`
- صف من 5 أزرار دائرية (1-5)
- يدعم لونين مختلفين (للمستوى وللاهتمام)
- الزر المحدد يأخذ لون الخلفية الممتلئة مع ظل
- الأزرار غير المحددة بحدود فقط

### 3.4 إنشاء Widget جديد: SkillCard
- **ملف جديد**: `projectforge_app/lib/widgets/skill_card.dart`

  - صفين: مستوى المهارة + الاهتمام
  - كل صف يحتوي عنوان + 5 أزرار دائرية

### 3.5 إنشاء Widget جديد: CategorySection
- **ملف جديد**: `projectforge_app/lib/widgets/category_section.dart`
