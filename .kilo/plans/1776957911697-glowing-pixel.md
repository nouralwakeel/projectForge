### Step 2: Create `skill_slider.dart`
**File:** `projectforge_app/lib/widgets/skill_slider.dart` (NEW)

A reusable widget for the skills survey screen. Currently the slider is inlined as a `ListTile` + `Slider` + `CircleAvatar` in `skills_survey_screen.dart:40-65`.

**Signature:**
```dart
class SkillSlider extends StatelessWidget {
  final String skillName;
  final int proficiency; // 0-5
  final ValueChanged<double> onChanged;
}
```

**Behavior:**
- Shows skill name, a `Slider` (0–5, 6 divisions), and a circular badge showing current level
- Level 0 = "غير محدد" (unselected)

### Step 3: Create `milestone_timeline.dart`
**File:** `projectforge_app/lib/widgets/milestone_timeline.dart` (NEW)

A vertical timeline widget for the sandbox screen. Currently milestones are rendered as a flat list of `Card` + `ListTile` in `sandbox_screen.dart:50-63`.

**Signature:**
```dart
class MilestoneTimeline extends StatelessWidget {
  final List<TimelineModel> timeline;
}
```

**Behavior:**
- Vertical list with connecting lines between items
- Each milestone shows: order number in circle, title, description, date range, estimated days
- Uses `Theme.of(context).primaryColor` for timeline line and circles

### Step 4: Create `match_badge.dart`
**File:** `projectforge_app/lib/widgets/match_badge.dart` (NEW)

A colored percentage badge for project cards and recommendation lists. Currently inlined as a `Container` + `Text` in `project_card.dart:38-49`.

**Signature:**
```dart
class MatchBadge extends StatelessWidget {
  final double percentage;
}
```

**Behavior:**
- Rounded container with percentage text
- Color from `AppTheme.matchColor()`: green ≥75%, yellow ≥50%, red <50%

### Step 5: Create `risk_card.dart`
**File:** `projectforge_app/lib/widgets/risk_card.dart` (NEW)

A card widget for displaying risk information. Currently inlined in `sandbox_screen.dart:68-87`.

**Signature:**
```dart
class RiskCard extends StatelessWidget {
```
