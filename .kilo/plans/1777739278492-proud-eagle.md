## Design Details

### Colors
All colors already exist in `AppTheme`:
- Primary gauge stroke: `AppTheme.primaryColor` (#A43073)
- Factor bars: primary (skillCoverage), tertiary (teamBalance), secondary (difficultyFactor)
- Insight card background: `AppTheme.secondaryContainer` (#FCDF46)
- Difficulty badge: `AppTheme.errorContainer` (#FFDAD6)
- Card backgrounds: `AppTheme.surfaceContainerLowest` (white)
- All text colors from `AppTheme.onSurface`, `AppTheme.onSurfaceVariant`

### Typography
Use `Theme.of(context).textTheme` with existing Lexend font:
- Display large (percentage): `fontSize: 40, fontWeight: w700`
- Headline medium (card titles): `fontSize: 24, fontWeight: w600`
- Label small (badges, tags): `fontSize: 13, fontWeight: w500`
- Body base (descriptions): `fontSize: 16, fontWeight: w400`

### Layout Approach
- Use `SingleChildScrollView` + `Column` for vertical scrolling
- Use `LayoutBuilder` to switch between mobile (single column) and tablet/desktop (multi-column)
- For the bento grid: `Row` + `Expanded` with `flex` values (8:4, 6:6)
- On mobile: full-width stacked cards
- Card styling: white background, `outlineVariant` border, 12px border radius, subtle shadow (`BoxShadow` with primary color at 8% opacity)
