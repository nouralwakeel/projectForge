# Plan: ربط Flutter مع Laravel + إعدادات IP + أزرار اختبار الاتصال + start.bat

## ملخص
إضافة نظام إعدادات ديناميكي لتطبيق Flutter يتيح للمستخدم تحديد عنوان IP ورقم المنفذ الخاص بـ Laravel API، مع أزرار اختبار الاتصال، وإنشاء ملف `start.bat`.

---

## 1. إنشاء `SettingsService` في Flutter
**ملف جديد:** `lib/services/settings_service.dart`
- خدمة GetX دائمة (permanent) تستخدم `shared_preferences`
- تخزن `api_ip` (default: `10.0.2.2` للأندرويد / `localhost` لغيره)
- تخزن `api_port` (default: `8000`)
- دالة `getBaseUrl()` تعيد `http://{ip}:{port}/api/v1`

## 2. تعديل `ApiConfig`
**ملف:** `lib/config/api_config.dart`
- إزالة `baseUrl` الثابت
- جعل `baseUrl` ديناميكياً يقرأ من `SettingsService`
- الاحتفاظ بجميع الـ endpoints كما هي

## 3. تعديل `ApiService`
**ملف:** `lib/services/api_service.dart`
- إضافة دالة `updateBaseUrl(String url)` تعيد بناء Dio بالـ baseUrl الجديد
- عند `onInit` يقرأ الـ baseUrl من `SettingsService`

## 4. إضافة `SettingsService` في `InitialBinding`
**ملف:** `lib/app/bindings/initial_binding.dart`
- تسجيل `SettingsService` قبل `ApiService` (لأن ApiService يعتمد عليها)

## 5. إنشاء شاشة الإعدادات `SettingsScreen`
**ملف جديد:** `lib/views/settings/settings_screen.dart`
- حقل إدخال **عنوان IP** (مع القيمة الحالية)
- حقل إدخال **رقم المنفذ** (مع القيمة الحالية)
- زر **حفظ الإعدادات** (يحفظ ويعيد بناء ApiService)
- زر **اختبار الاتصال مع API** (يرسل GET إلى `/majors` - endpoint عام لا يتطلب auth)
- زر **اختبار الاتصال مع قاعدة البيانات** (يرسل GET إلى `/health/db` - endpoint جديد في Laravel)
- عرض نتائج الاختبار (نجاح/فشل مع رسالة توضيحية)

## 6. إنشاء `SettingsController`
**ملف جديد:** `lib/controllers/settings_controller.dart`
- يتحكم في حقول IP والمنفذ
- دالة `saveSettings()` تحفظ وتبني Dio من جديد
- دالة `testApiConnection()` ترسل GET إلى `{baseUrl}/majors`
- دالة `testDbConnection()` ترسل GET إلى `{baseUrl}/health/db`

## 7. إضافة Route للإعدادات
**ملف:** `lib/app/routes/app_routes.dart`
- إضافة `static const String settings = '/settings';`

**ملف:** `lib/app/routes/app_pages.dart`
- إضافة GetPage للإعدادات مع SettingsController binding

## 9. إضافة Endpoint لاختبار قاعدة البيانات في Laravel
**ملف جديد:** `backend/app/Http/Controllers/API/HealthController.php`
- دالة `checkDb()` تجري `DB::connection()->getPdo()` وتعيد نجاح/فشل
- Endpoint عام بدون auth

**تعديل:** `backend/routes/api.php`
- إضافة `Route::get('/health/db', [HealthController::class, 'checkDb'])` داخل prefix `v1` خارج middleware auth

## 10. إنشاء `start.bat`
**ملف جديد:** `start.bat` في جذر المشروع (`C:\projectForge\start.bat`)
```bat
@echo off
echo Starting Laravel Server on 0.0.0.0:8000...
cd /d "%~dp0backend"
php artisan serve --host=0.0.0.0 --port=8000
pause
```
