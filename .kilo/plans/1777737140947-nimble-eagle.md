# Plan: Redesign Flutter Survey Screen to Match HTML

## Problem
The current Flutter survey screen doesn't match the provided HTML design. Key visual gaps: button sizes, color schemes per category, layout differences, missing English subtitles, wrong progress bar style, and missing submit button styling.

---

## Analysis of HTML vs Current Flutter

### Color Schemes Per Category (from HTML)

| Category | Bar Color | Proficiency Inactive Border | Proficiency Active BG | Proficiency Active Text | Interest Inactive Border | Interest Active BG | Interest Active Text |
|---|---|---|---|---|---|---|---|
| Cybersecurity | `tertiary` (#7B41B4) | `tertiaryContainer` (#C084FC) | `tertiary` (#7B41B4) | `onTertiary` (white) | `secondaryContainer` (#FCDF46) | `secondaryFixed` (#FFE24C) | `onSecondaryFixed` (#211B00) |
| IoT | `surfaceContainerHighest` (#D3E4FE) | `surfaceContainerHighest` (#D3E4FE) | `surfaceDim` (#CBDBF5) | `onSurface` (#0B1C30) | same | same | same |
| Soft Skills | `primary` (#A43073) | `primaryContainer` (#F472B6) | `primary` (#A43073) | `onPrimary` (white) | same | same | same |

**Interest buttons are identical across ALL categories** — always yellow (`secondaryContainer`/`secondaryFixed`).

### Layout Differences Per Category

1. **Cybersecurity & IoT**: Each skill card is full-width, proficiency + interest displayed **side-by-side** in a 2-column grid (`grid-cols-1 sm:grid-cols-2`)
2. **Soft Skills**: The skill cards themselves are arranged in a **2-column grid** (`grid-cols-1 md:grid-cols-2`), with proficiency + interest **stacked vertically** inside each card

### Structural HTML Elements Not Yet Matched

- Button size: `w-8 h-8` (32x32) — current is 40x40
- Category top bar: `h-1` (4px) — current is 6px
- Icon in a container: `w-10 h-10 rounded-lg bg-{color}/20` — current has no container
- English subtitle: `(Cybersecurity)` after Arabic title — current missing
- Progress dots: `w-16 h-2` bars — current uses small dots
- Submit button: `shadow-[0_4px_14px_0_rgba(164,48,115,0.39)]` with send icon and `border-b-2 border-on-primary-fixed-variant`
- Skill card: `bg-surface rounded-lg p-5 border border-outline-variant/20 shadow-sm` — current lacks border and proper surface bg
- Category card: `border border-outline-variant/30` — current missing border

### Missing AppTheme Colors
- `secondaryFixed` = `#FFE24C` (needed for interest active state)
- `onSecondaryFixed` = `#211B00` (needed for interest active text)

## Implementation Steps

### Step 1: Add missing colors to `app_theme.dart`
Add two constants:
```dart
static const Color secondaryFixed = Color(0xFFFFE24C);
static const Color onSecondaryFixed = Color(0xFF211B00);
```

### Step 2: Create `CategoryStyle` data class
**New file**: `projectforge_app/lib/widgets/category_style.dart`

Holds per-category visual config:
- `barColor` — top bar color
- `iconBgColor` — icon container background (20% opacity)
- `profInactiveBorder` — inactive proficiency button border color
- `profActiveBg` — active proficiency button background
- `profActiveText` — active proficiency button text
- `englishTitle` — English subtitle string
- `useSideBySideLayout` — true for Cybersecurity/IoT, false for Soft Skills
- `useSkillGrid` — true for Soft Skills (2-col grid of skill cards)

Define a static map with all 11 category styles (parts 1, 2, and 3).

**Color assignments for Parts 1 & 2** (following the same pattern as Part 3):

| Category | Proficiency Theme | Bar Color |
|---|---|---|
| Frontend | primary | primary |
| Programming Languages | tertiary | tertiary |
| Backend | onPrimaryFixedVariant | onPrimaryFixedVariant |
| Databases | surfaceDim | surfaceContainerHighest |
| AI/ML | tertiary | tertiaryFixedDim |
| Tools | secondary | secondaryFixedDim |
| Cloud | surfaceDim | surfaceContainerHigh |
| Design | primary | primaryFixedDim |

### Step 3: Rewrite `skill_rating_buttons.dart`
- Button size: 32x32 (matching `w-8 h-8`)
- Accept 3 color params: `inactiveBorderColor`, `activeBgColor`, `activeTextColor`
- Active: filled circle with `activeBgColor`, text in `activeTextColor`, elevation/shadow
- Inactive: transparent bg, `inactiveBorderColor` border (2px width), grey text
- LTR direction (already present)

### Step 4: Rewrite `skill_card.dart`
- Accept `CategoryStyle` parameter
- Card container: `surfaceColor` bg, `rounded-lg`, `p-5`, `border outlineVariant/20`, light shadow
- Two layout modes controlled by `categoryStyle.useSideBySideLayout`:
  - **Side-by-side** (Cybersecurity/IoT): `Row` with 2 `Expanded` children (proficiency | interest)
  - **Stacked** (Soft Skills): `Column` with proficiency then interest vertically
- Each rating section: label text on top, buttons below
- Proficiency buttons use category-specific colors from style
- Interest buttons always use yellow scheme (secondaryContainer/secondaryFixed)

### Step 5: Rewrite `category_section.dart`
- Add `englishTitle` parameter (optional)
- Add `iconBgColor` parameter
- Top bar: 4px height (not 6px)
- Icon: wrapped in `Container` (40x40, rounded-lg, iconBgColor background)
- Title: `onSurface` color (not barColor), with English subtitle in lighter text
- Card border: `border: Border.all(color: outlineVariant.withOpacity(0.3))`
- Add `useGrid` parameter — when true, wraps children in `Wrap` or `GridView` for 2-column layout (Soft Skills)
- Content padding: `p-6`

### Step 6: Rewrite `skills_survey_screen.dart`
- Progress indicator: 3 bars `width: 64, height: 8` (matching `w-16 h-2`), active = primary, inactive = surfaceVariant
- Import and use `CategoryStyle.map` for each category
- Pass full `CategoryStyle` to `CategorySection` instead of just bar color
- For Soft Skills: set `useGrid: true` on `CategorySection`
- Submit button styling:
  - `bg-primary`, `text-on-primary`
  - Custom shadow: `BoxShadow(color: primaryColor.withOpacity(0.39), blurRadius: 14, offset: Offset(0, 4))`
  - Bottom border: `Border(bottom: BorderSide(color: onPrimaryFixedVariant, width: 2))`
  - Add send icon (`Icons.send`) after text
  - Rounded-xl, py-4, px-12
- Header title: `fontSize: 40, fontWeight: FontWeight.w700` (matching `display-lg`) — may need scaling for mobile
- Header subtitle: `fontSize: 24, fontWeight: FontWeight.w600` (matching `headline-md`)
- "Previous" button on steps 2 & 3

### Step 7: Run `flutter analyze` to verify zero issues
